# Plugins

Skill bundles that are designed to run as a set rather than individually.

| Plugin | What it does |
|--------|--------------|
| [meeting-intelligence](meeting-intelligence/) | Meeting lifecycle — prep, rehearsal, capture, synthesis — with a blunt self-evaluation on every call, plus cross-interview scoring. |
| [chief-of-staff](chief-of-staff/) | Six skills that hold the whole picture of your work — project health, task clarification, prioritization, execution, and decision follow-through. Start here if you want the CoS pattern. |

Individual skills live in [`../skills/`](../skills/). A plugin README explains how its
skills relate to each other and what they require; the skills themselves are still
installable one at a time.
